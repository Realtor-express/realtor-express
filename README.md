# Realtor Express

**Realtor Express** is a B2B2C platform for the New York City real estate market designed to cut deal closing time from 90 to 30 days. It connects verified agents with clients through an intelligent matching system while ensuring full privacy.

## Core Concept
The platform operates in two distinct modes:
*   **Agent Mode (B2B):** A professional dashboard for realtors to receive matched client leads, manage communications with contact privacy, and access performance analytics.
*   **Client Mode (B2C):** A simple 7-step questionnaire for buyers/sellers/renters to get matched with 3-5 vetted agents within hours, not weeks.

## Key Features (MVP Scope)
*   Dual-role authentication (Agent/Client)
*   7-step intelligent client questionnaire
*   Algorithmic agent-client matching (based on location, specialty, budget, timeline)
*   Lead feed for agents with templated quick responses
*   Contact privacy layer (contacts revealed only upon mutual agreement)
*   Basic profiles, listings, and in-app messaging
*   Admin dashboard for user & listing management
